## 📘 Python Concepts + Exercises

These files cover **must-know Python topics** often used in data science, including:

### List Comprehensions  
- Filtering and transforming data in one line.  
- Practice examples: removing punctuation from strings, selecting names based on conditions, and pairing values using `zip`.

### Exception Handling  
- Used `try-except` blocks to:  
  - Catch and handle non-integer values in lists or dictionaries.  
  - Manage missing data in structured formats.  
  - Safely read files using `with open()` and handle `FileNotFoundError`.

### File Handling (CSV & JSON)  
- Opened, read, wrote, and updated `.csv` and `.json` files.  
- Ensured **safe file writing** using `with open()` and correct modes (`'r'`, `'w'`, `'a'`).  
- Learned how to:  
  - Use `json.load()` and `json.dump()` properly.  
  - Read CSVs using Python’s built-in `csv` module and explore basic parsing.  
  - Append to files the **right way** (read → update → write flow).

### Lambda Functions  
- Practiced writing **anonymous functions** with `lambda` for short, clean logic.  
- Applied with `map()`, `filter()`, and `sorted()` to:  
  - Apply transformations to lists.  
  - Filter elements based on conditions.  
  - Sort data with custom rules (e.g., by string length, value).
