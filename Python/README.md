#  Python Practice & Projects Repository

This folder contains Python scripts, hands-on exercises, and examples focused on solving real-world problems while demonstrating Python’s versatility — especially for data science and machine learning.

It includes foundational concepts, exception handling, NumPy operations, and list comprehensions with practical use cases and mini challenges.

---

## 📁 Contents

### 🔹 Projects
- **data.py**: Script for managing and interacting with datasets.
- **finance_data.csv**: Sample financial data used for basic analysis.
- **main.py**: Main project script that showcases structured Python code for data processing and logic implementation.

---

## 📘 Python Concepts + Exercises

These files cover **must-know Python topics** often used in data science, including:

### List Comprehensions
- Filtering and transforming data in one line.
- Practice examples: removing punctuation from strings, selecting names based on conditions, and pairing values using `zip`.

### Exception Handling
- Used `try-except` blocks to:
  - Catch and handle non-integer values in lists or dictionaries.
  - Manage missing data in structured formats.
  - Safely read files using `with open()` and handle `FileNotFoundError`.
